- INT、BIGINT、FLOAT、VARCHAR、VARCHAR(n)、DECIMAL、BOOL、DATE。
- 主键、唯一、CHECK、默认值、NOT NULL、外键和显式事务。
- 页式存储、目录持久化、缓冲池基础能力、WAL 重做恢复、显式 CHECKPOINT，以及在成功提交后按写语句数、已提交日志大小、提交脏页数量、脏页比例和时间窗口触发的自动 CHECKPOINT；当前为提交事件驱动策略，详见 `docs/auto-checkpoint-progress.md`。
- B+ 树核心：复合键、点查、范围查、叶/内部节点分裂、重复键检测和结构校验。
- SQL 索引：CREATE INDEX、CREATE UNIQUE INDEX、DROP INDEX、单列等值/范围 IndexScan、复合等值/前缀范围 IndexScan、索引元数据和 B+ 树快照持久化、指纹校验、损坏回退、重启重建、写路径维护和唯一约束。
- 索引页落盘：B+ 树镜像从 JSON sidecar 迁移到页文件 owner 页，Catalog 展示 `storage/pageCount/height`，支持多级树、重启恢复和 `MINISQL_REBUILD_INDEXES` 强制重建；44 项索引持久化检查通过，详见 `docs/index-page-storage-progress.md`。
- 优化器固定点、常量折叠、布尔化简、恒真过滤器删除及预算保护。
- React 工作台真实 C++ 连接、编译/执行、事务、错误定位、查询历史、主题、结果上限、CSV 导出、选区复制、健康状态和存储页统计。
- Catalog 真实表行数、表页数、缓存命中/读写和淘汰日志。
- 结果行预算：单条语句返回行数超过 `MINISQL_MAX_RESULT_ROWS` 时明确拒绝，LIMIT 和聚合结果不受误判影响。
- 服务端查询取消：HTTP bridge 通过 sessionId 绑定取消文件，C++ 在扫描、连接、聚合和外部排序中轮询取消令牌；取消返回 5002，会话可继续使用，临时 run 会清理。
- 多会话并发控制：SessionRegistry 支持多个逻辑 HTTP 会话、会话级事务状态与取消文件、数据库级保守两阶段锁、锁等待超时、关闭/空闲回滚和 `GET /api/sessions` 状态查询；44 项专项检查通过，详见 `docs/concurrency-progress.md`。
- 外部聚合：分组输入记录超过内存行预算时写入带校验的 JSONL run，按分组键外部排序并流式合并状态；低预算专项检查通过。
- 外部排序：ORDER BY 输入超过内存行预算时按块写入 JSONL run，再进行多路归并；临时文件带 sessionId、查询/排序序号和 FNV-1a 校验，查询结束或异常时清理；支持 MINISQL_SORT_MEMORY_ROWS 和 MINISQL_TEMP_DIR。
- 流式结果传输：只读 NDJSON execute stream、HTTP drain 背压、执行器 `RowStream`、Limit 提前停止、C++ `executeStreaming` 和会话级多帧 `meta/row/complete` 已接通；x25 流式 HTTP 18 项、session stream 9 项通过。排序/聚合完全逐行生产作为后续增强，详见 `docs/streaming-progress.md`。
- 表/列统计接口：行数、页数、distinct 数、NULL 数和 NULL 比例。
- EXPLAIN 原始/优化计划、查询级和逐节点 EXPLAIN ANALYZE 实际统计，以及基于表/列统计的 stats-v1 估计行数/成本。
- 保守谓词下推：INNER JOIN 上的单表安全条件可下推到对应输入，LEFT JOIN、算术和跨表条件保持原位。
- 等值 INNER JOIN 改写为 HashJoin，执行结果与 NestedLoopJoin 等价并保留重复行。
- 保守列裁剪：`Project -> Filter? -> SeqScan` 只保留投影和过滤实际引用的扫描列，字面量投影可裁剪为零列。
- 语句级批量诊断：一次请求返回多条语句的语法/语义错误，不执行任何写操作。
- HTTP 审计日志：记录用户、会话、路径、SQL 摘要、状态、耗时、影响行数和错误码，并提供有上限的查询接口。
- HTTP 基础权限：admin/reader/writer 用户策略，按 SELECT/INSERT/UPDATE/DELETE/CREATE/TRANSACTION/COMPILE 拒绝越权请求。
- 访问控制深化：页式访问目录、用户/角色/角色继承、对象级 SELECT/INSERT/UPDATE/DELETE、加盐密码、会话身份绑定、可见元数据过滤、审计过滤、原子 HTTP 资源端点和权限感知 CLI 已接入；43 项 HTTP 闭环、27 项原子接口、39 项原子 HTTP、11 项 CLI 契约通过，详见 `docs/access-control-progress.md`。
- 文件级备份恢复：CHECKPOINT 后复制数据库文件，写入 v2 清单（页格式版本、WAL 截止位置、大小和 SHA-256），支持 v1 清单迁移、未知版本拒绝、校验恢复和备份列表。
- 在线备份快照：新增 v4 在线一致性快照、WAL/`.ckpt` sidecar 复制、非零截止位置恢复、恢复回滚目录和页校验，在线快照 19 项检查通过；增量 v3 `.delta` 链式恢复仍保持 50 项专项通过，详见 `docs/backup-format-progress.md`。
- 非相关子查询：IN、NOT IN、EXISTS 和标量子查询，含 NULL 三值逻辑、空结果和错误拒绝。
- 相关子查询：限定名外层引用（如 `x.id`）的 EXISTS、IN 和标量子查询，按外层行执行并支持 NULL/空结果。
- AST/Plan JSON 反序列化、版本包装、父子引用校验和序列化往返。
- FLOAT 的 SQL 字面量、列、表达式、比较、聚合、显式 CAST、持久化和跨进程重启。
- 逻辑计划 JSON 数组/版本包装反序列化、父子节点校验和序列化往返。
