# SQL 编辑器操作

日期：2026-09-08。对应 REQ-UI-003、REQ-UI-004 的编辑操作，完整验收仍有剩余项。

## 一、执行范围与快捷键

Run 和 Compile 优先处理 CodeMirror 主选区，没有选区时处理整个标签。空白选区不执行，也不退回执行全文。选中内容直接发送，不使用前端字符串分割器按分号拆句。结果标明“选区结果”，并保留整份编辑器快照，用于检测执行后 SQL 是否改变。事务工具栏命令不受编辑器选区影响。

编辑器内 Ctrl/Command+Enter 执行，Ctrl/Command+Shift+Enter 编译；Ctrl/Command+S 导出当前完整 SQL，Ctrl/Command+O 打开导入选择器。组合输入期间不触发快捷键，执行仍受忙状态、会话和事务状态保护。切换标签重建该标签的编辑器，避免沿用另一标签的选区；每标签光标/滚动位置恢复仍待实现。

## 二、文件与草稿

导入 .sql 文件会新建标签，不覆盖当前草稿；只接受有效 UTF-8，最大 8 MiB，继续遵守最多 50 个标签限制。TextDecoder 按标准处理 UTF-8 BOM，不承诺保留 BOM 字节。导出使用当前完整 SQL，即使有选区也不会只导出选中内容；文件名过滤路径分隔符等字符，必要时补 .sql 后缀。

导出通过浏览器下载机制完成，不把发起下载等同于用户已经完成磁盘保存，因此不会自动取消关闭草稿确认。浏览器草稿存储失败会显示持续告警，页面内编辑内容不丢弃；用户仍可导出 SQL。
