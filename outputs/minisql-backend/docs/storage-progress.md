# 页式存储基础实施记录

日期：2026-09-08。对应 V3 第五章与第十七章中的页、记录槽位、文件生命周期需求。此记录不代表数据库端到端或全部扩展已完成。

## 已实现

1. SlottedPage 使用固定 4096 字节、64 字节页头和每项 16 字节槽目录。页头记录版本、页号、所属表、页代次、槽数量和空闲边界；数据从页尾向前放置。
2. 插入、读取、删除、槽复用和页内压缩。压缩保持存活槽位身份，复用递增槽代次；引用旧代次报错。
3. 小端字段编解码和整页校验；载入验证页头、目录边界、记录范围和重叠区间。空物理记录拒绝，单条最大记录为 4016 字节。
4. PageFile 保留第 0 页作为文件头，数据页使用唯一活动页号。释放页在磁盘中保存空闲标记和代次，重开扫描并恢复分配状态；复用递增页代次。
5. 页所有权检查，拒绝旧引用、重复释放和释放保留页；页文件长度与页计数校验。
6. 短读、写入或 flush 错误后停用当前文件句柄，后续写入拒绝，要求重新打开检查。

## 实际验证

本机 g++ 以 C++20、Wall、Wextra 编译存储契约测试，退出码 0，无输出警告。运行 bin/storage_contract.exe，31 项检查通过。

测试覆盖：插入读取、删除、槽复用代次、页内压缩、整页序列化往返、精确容量、失败插入无变化、坏校验、坏槽边界、目录越界、页号唯一、释放后拒读、双重释放、保留页保护、分配状态重开、记录重开、空闲页重用、旧页引用、所属表篡改、删除持久性、文件长度、截断、坏文件头、运行时短读以及错误后的写入禁止。

测试文件保存在 tests/artifacts/storage-38765666127000，每次运行使用新的独立目录，不覆盖用户数据库。CMake 已登记存储库和 minisql_storage_contract 测试；完整 vcpkg/CMake 构建尚未在本轮验证。

## 限制与后续

1. 当前记录载荷是字节序列；SQL 行的类型编码、NULL、变长列格式尚未接入。
2. 未实现 Buffer Pool、pin 计数、LRU/FIFO、缓存统计或页释放与缓存失效联动。
3. 未实现页式系统目录、表页链、SQL 执行器和真实数据库重启查询；不能以本轮文件重开测试代替完整数据库验收。
4. 文件 flush 是流刷新，不承诺操作系统断电持久性；无 WAL、事务原子性、故障恢复或多进程文件锁。多步分配失败可能留下需检查状态，不声称自动回滚。
5. 空闲页恢复目前在打开时扫描整份文件；后续可增加持久空闲目录，但不能牺牲现有有效性检查。
6. 本轮页引用与槽引用分别携带代次；执行引擎接入时需组合成完整行定位，并同步公共 Rid 定义。
