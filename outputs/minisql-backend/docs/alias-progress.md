# 表别名与限定列实现

日期：2026-09-08。对应 EXT-SQL-010，同时为 EXT-SQL-008 的多表作用域提供基础；两项均不据此判为完整完成。

## 一、已支持行为

1. SELECT 的 FROM 支持显式 AS 表别名和省略 AS 的表别名，别名仅在当前语句有效，名称比较不区分大小写。
2. 表别名存在时，限定列必须使用该别名；没有别名时可以用真实表名限定。未知限定名、未知列及跨语句泄漏的别名均报语义错误。
3. 限定列可用于投影表达式、WHERE、ORDER BY。最终绑定到实际列编号；执行计划中的 table 仍是真实表名，不改变持久化 Catalog。
4. 星号与限定星号按目录列顺序展开，可以与其他投影混合，可以重复，保留所有输出位置。星号不能整体添加输出别名。
5. 投影别名在 ORDER BY 可见，在 WHERE 不可见；重复输出别名被引用时拒绝。限定的同源列投影别名与源列同名时，不再被误判为冲突。
6. AST 增加 tableAlias，星号投影表示为 Wildcard 节点。selectList 继续保留简单引用/星号信息，但不是完整投影结构。
7. 词法器新增点分隔符，数字后带点及点后数字的浮点写法仍被拒绝，未因此启用小数类型。

## 二、实现位置

Parser 构建别名、限定名和 Wildcard。Catalog 使用局部绑定表副本，不修改正式目录，并由 resolveColumnName 统一检查限定名。Planner 复用相同绑定规则，展开每个星号为真实列投影；Execution 继续消费列编号，无需把别名传入存储层。

词法语法 12 项、语义计划 25 项、UPDATE 30 项、优化器 117 项通过。HTTP 38 项通过，包含带别名执行和错误限定名拒绝。浏览器 DOM 12 项通过，实际编译并显示 tableAlias。没有生成或读取图片。

重新执行固定种子差分测试，共 500 次检查通过，无结果差异或诊断异常，报告位于 `tests/artifacts/fuzz-FjzUG1/report.json`。这批随机语料主要检查已有非限定查询的兼容性，限定名专项由上述 37 项测试负责，不能把该随机运行宣称为多表测试。
