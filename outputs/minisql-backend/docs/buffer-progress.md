# Buffer Pool 实施记录

日期：2026-09-08。范围：V3 第五章、第 17.4 节。仍属于完整数据库实现的中间阶段。

## 已实现

1. 固定容量缓存、LRU 和 FIFO 两种替换策略。命中更新访问序号但不更改加载序号；只能淘汰 pins 为零的帧。
2. PageGuard 自动增减固定计数，禁止复制，支持移动。提供只读页访问和受控插入/删除，写入成功后标脏；不暴露可任意替换页身份的可变引用。
3. 脏页淘汰前写回并刷新文件，成功后清脏；失败保留帧和脏标记，不记录成功淘汰。
4. 页释放先检查未固定，写入释放状态后清除对应缓存；旧代次访问拒绝，避免释放后残留脏页覆盖复用数据。
5. 全部页固定时报 BUFFER_EXHAUSTED；固定页禁止释放和刷新。策略切换先刷新全部页、清空缓存、清零统计。
6. 记录 hit、miss、缓存页读写和写回错误次数，以及淘汰页、代次、策略、序号和原脏状态。

tests/buffer_contract.cpp：35 项检查通过。确定性序列 A、B、C、A、D、A，容量为 3，LRU 为 2 hit/4 miss，首次淘汰 B；FIFO 为 1 hit/5 miss，首次淘汰 A。

其他检查包含容量限制、固定保护、多个 Guard、移动赋值、已移动 Guard 拒绝访问、退出作用域释放 pin、脏页淘汰持久化、重复清洁刷新不写盘、删除刷新、释放失效、页代次复用、策略切换、无效容量及写回失败保留脏状态。

## 未完成与使用约束

1. 当前为单线程缓存，不提供并发互斥或事务锁。并发控制扩展不能凭 pin 计数宣称完成。
2. 使用期间应由唯一 BufferPool 管理相应 PageFile；不能绕过缓存直接修改或释放文件页。PageGuard 只能在所属缓存生命周期内使用，持久化关闭须先释放全部 Guard，再显式 flushAll。
3. 统计目前只覆盖缓存触发的页加载/写回，不包含文件头、分配和释放元数据 I/O。系统级统计与前端展示尚未接通。
4. 淘汰事件目前保存在内存中；有界日志、完整 I/O 失败事件与日志导出仍需补齐。
5. 尚未接入页式 Catalog、执行算子和四类 SQL 的持久化测试。课程完整数据库验收尚未完成，27 组扩展目标不变。
