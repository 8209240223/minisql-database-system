# 多标签查询状态与草稿

日期：2026-09-08。对应 REQ-UI-003、REQ-UI-004 的部分实现，不是工作台全部验收报告。

## 一、实现行为

每个查询标签按独立 ID 保存 SQL、结果、错误文本、结果视图和执行时 SQL。切换标签不会借用另一标签的结果。异步请求绑定发起标签，响应返回时更新原标签；编辑器内容已改变时保留结果并提示“结果对应旧 SQL”。执行中的标签不可关闭，其他标签可以切换和编辑。

事务仍属于当前公共连接会话。某标签保留的 pending 结果会在其他标签提交或回滚时更新状态；回滚后保留历史结果并标记“事务已回滚”。工具栏事务命令不覆盖编辑器查询结果。连接切换、断开和会话过期清除全部标签的旧连接结果，保留 SQL 草稿。

支持图标按钮重命名查询，名称最多 100 字符；修改过的标签关闭前要求确认。最多保留 50 个标签。草稿写入浏览器 localStorage，刷新恢复 SQL 和名称，不恢复会话、事务或旧结果。恢复时校验结构、ID、重复 ID、数量、名称及 SQL 长度，损坏内容退回初始草稿。
