## 实现

SELECT DISTINCT 在 AST 中保存独立标记；计划在 Project 之上增加 Distinct 节点，继承输出列结构。执行先完成过滤及投影，再对完整结果行去重，保留第一次出现的行。此顺序只是当前实现行为，不构成未使用 ORDER BY 时的排序承诺。

去重使用标准有序集合存储完整 JSON 行数组，比较覆盖全部列，不拼接字符串键，因此不会把不同列组合误当作相同结果。计算列、重复输出列名和空结果保留原有列顺序与结构。
