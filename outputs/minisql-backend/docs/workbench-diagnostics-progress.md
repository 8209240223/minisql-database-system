## 一、实现行为

真实 MiniSQL C++ 返回的行列号先按此次提交源码解释，再映射到完整编辑器文档。选区可能从行中间开始；第一行列偏移、后续行号、Unicode 码点及 CR/LF/CRLF 均纳入转换。CodeMirror 使用规范化换行后的 UTF-16 偏移，后端使用从 1 开始的 Unicode 码点列号，两者不会直接混用。

错误位置和执行时文档快照保存在发起请求的标签中。定位图标显示完整源码的行列号，点击后滚动至错误位置并选中对应字符；文件末尾错误放置光标，不越界选择。没有有效行列号或位置超出所提交源码时不创建虚假定位。

当前文档与错误快照不一致时显示“原 SQL 已修改”并禁用跳转。清除错误或发起新请求会清除对应旧定位。诊断栏允许换行，长错误文本允许折行。

编辑器使用 CodeMirror lint 组件显示错误字符下划线、行边错误标记和悬停消息。EOF 使用零长度诊断标记，不人为扩大到前一个字符。诊断由各标签的执行快照驱动；修改后清除，恢复相同源码后重新显示，切换标签时随各自诊断恢复。关闭错误消息会同步清除编辑器标记。仅提交已有后端起始位置，不推测未提供的结束位置。
