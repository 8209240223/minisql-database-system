# 工作台事务控制

日期：2026-09-08。React 工作台已接入真实 C++ HTTP 会话，不使用 Demo 引擎模拟后端事务。

## 一、界面和请求路径

切换到 MiniSQL C++ 后，用户显式连接会话。工具栏提供连接、断开、开始事务、提交和回滚图标按钮，包含按钮名称和悬停提示。查询、编译与目录请求携带当前 sessionId，所有查询标签共用当前连接会话。

显示未连接、自动提交、事务进行中/未提交、事务失败/必须回滚、会话已过期、提交状态未知。BEGIN/COMMIT/ROLLBACK 按真实 SQL 发送；ABORTED 时禁用提交并允许回滚，UNKNOWN 时禁止继续运行和编译。请求执行期间禁用重复操作和连接切换。

切换连接或断开活动事务前要求确认。未知提交状态的确认明确说明断开不会撤销已提交数据。会话过期后清除 sessionId 和目录，要求重新连接，不自动重试写请求。页面离开尝试以 keepalive 关闭会话，若关闭消息未送达仍由后端空闲超时回滚；不承诺浏览器退出时网络消息一定送达。

客户端保留错误响应中的事务状态、提交状态、HTTP 状态和执行结果，避免把所有失败都降为纯文本。事务执行失败后重新读取回滚后的目录。
