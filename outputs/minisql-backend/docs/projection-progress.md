# 投影表达式实施记录

日期：2026-09-08。对应 EXT-SQL-010 的单表投影子范围。

## 已实现

SELECT 清单允许表达式及显式 AS 别名。AST 保存 SelectItem 的表达式和别名，语义检查所有表达式，计划保存绑定表达式、结果类型和输出名。执行阶段先 Filter，后求投影表达式；优化器也处理投影里的常量表达式。

直接列引用未提供别名时保留目录中的列名；计算表达式未提供别名时使用 expr_1 等稳定位置名称。重复列及重复输出别名保留为按位置排列的结果数组，不用同名对象键覆盖。WHERE 名称解析仍限源表，不可引用同层投影别名。

## 验证

优化与表达式联合测试从 51 项增至 63 项并通过。新增检查覆盖计算值、字符串及 BOOL 输出、别名、重复别名、重复结果行、自动命名、别名不可见、缺列、类型错误，以及优化开关对结果和除零错误的等价性。WHERE 为假时不求投影中的除零。

独立编译器已重建，12 项词法/语法和 25 项语义/计划回归再次通过。编译器 AST JSON 增加 selectItems，计划 JSON 增加 projections，原有 selectList 为简单列引用保留兼容信息，不代表完整表达式清单。

## 初版未完成范围（历史记录）

表别名、多表限定列、限定星号、ORDER BY 别名解析和 JOIN 尚未实现；EXT-SQL-010 不能标为全部完成。计算列当前内部 columnId 使用非源列标记，后续需统一稳定输出列身份，不能把该标记当成真实源列索引。类型、错误定位和接口格式仍需随更多类型与多表作用域一起完善。

## 后续更新

截至 2026-09-08，ORDER BY 别名解析、单表表别名、限定列、限定星号及混合星号已接入并测试，详见 sort-progress.md、alias-progress.md。JOIN、多表作用域和稳定计算列身份仍未完成，上述初版记录不作为当前能力清单。
